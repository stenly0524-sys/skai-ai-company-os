資料備份與還原

本機 IndexedDB 儲存資料，Google Drive 備份需要自己的 Google OAuth 網頁用戶端 ID。未設定前可匯出 JSON 至「檔案」App，再手動存入 Google Drive。

Google Drive 直接備份

需於 Google Cloud 設定「已授權的 JavaScript 來源」為本站網址；採用 drive.file 權限，僅操作本應用建立的備份檔。

尚未備份。iPhone 清除網站資料可能刪除本機紀錄。
